# Nereidonia Foundation Website Prototype

This repository now contains an implementation-ready static website prototype for the Nereidonia Foundation v1 information architecture.

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## Included sections

- Home
- Stories (including 3 complete sample story detail pages)
- Partners (including sample partner profile)
- Transparency (dashboard, disbursements, operations, impact calculator, reports, API plan)
- About
- Resources
- Blog / News
- Get Involved
- Press / Media
- Legal + sitemap

## Notes

- The structure is designed to map cleanly to Wix pages and CMS collections.
- Content and figures are seeded so the site can be reviewed end-to-end and refined for production.
